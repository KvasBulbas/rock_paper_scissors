# rock_paper_scissors

1.Сборка:
1.1 Запуск приложения через qtcreator(windows и linux)
1.Открываем qtcreator
2.Нажимаем открыть проект
3.выбираем rock_paper_scissors.pro

1.1 Запуск приложения через exe на windows на Qt 5.12.2
1.Для начала нужно выбрать версию сборки (release или debug в qtcreator) и найти папку этой сборки, где будет exe файл
2.Для того, чтобы приложение можно было запустить через exe я использовал windeployqt, находящийся в папке Qt/5.12.2/mingw81_64/bin,
 поскольку по умолчанию в папке со сборкой отсутсвтуют некоторые файлы необходимые для запуска. Также эти файлы можно перетащить 
вручную из папки Qt/5.12.2/mingw81_64/bin в папку сборки.
На всякий случай прикрепляю архив с готовой сборкой (release) приложения с рабочим файлом exe

2.О программе:
2.1 Взаимодействие с интерфейсом и фишки:
Чтобы начать игру одному игроку нужно создать сервер, после чего другой игрок должен ввести ip адрес и нажать подключиться.
Адреса, по которым можно подключиться, будут выведены у создателя сервера, или же можно использовать localhost (в случае игры на одном
устройстве), адрес которого введен в строку по умолчанию. Также можно отменить решение пользователя в меню локального подключения
с помощью esc, к примеру, в случае если пользователь передумал создавать сервер или случайно нажал на кнопку подключиться, 
когда сервер не был создан, или был введен неверный адрес. 
Также, если во время игры пользователь, находящийся со стороны клиента, отключился, то он может перезайти, снова введя адрес,
если же пользователь-хост отключился, то сам сервер закрывается, и в таком случае придется создавать новую игру.

2.2 Устройство работы и основные решения:
Приложение начинает работать с того, что в main.cpp инициализируется объект класса-виджета главного окна (MainWindowWidget).
Через него отображаются все остальные "главные" виджеты (MainMenuWIdget, LocalhostWidget, GameWidget), которые сменяют друг друга.
Взаимодействие между виджетами и виджетов с сервром происходит через класс ApliсationManager, который также хранит в себе объект класса
ServerManager, через который происходит взаимодействие с сервером и клиентом, AplicationManager, в случае необходимости, может его
предостваить.

UPD:
Также хочу подметить, что не расписывал в комментариях к коду, как устроена работа виджетов, потому что для каждого виджета это
было бы очень грамоздко, поэтому опишу здесь: для того чтобы один виджет отображался в другом, достаточно при создании одного
указать в конструкторе в качетсве параметра parent дургой виджет, в котором мы хотим его отобразить, в таком случае нам также
не нужно будет особождать память в ручную, поскольку, при удалении родительского виджета, память его потомков осободиться неявно.
Также я не расписывал как происходит выравнивание виджетов, поскольку мне показалось, что это не важно, ведь это не влеяет на работу
программы, а просто добавляет стилистческие изменения в интерфейс.
